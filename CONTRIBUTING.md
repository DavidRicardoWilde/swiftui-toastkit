# Contributing to ToastKit

Thanks for your interest in improving ToastKit. Bug reports, documentation fixes, examples, and focused pull requests are welcome.

## Start a conversation

- Use [GitHub Discussions](https://github.com/DavidRicardoWilde/swiftui-toastkit/discussions) for questions, design ideas, and general feedback.
- Use [GitHub Issues](https://github.com/DavidRicardoWilde/swiftui-toastkit/issues/new/choose) for reproducible bugs and specific feature requests.
- For a bug, include a minimal Swift example, reproduction steps, actual and expected behavior, screenshots when useful, and your iOS/iPadOS, device or simulator, Xcode, Swift, and ToastKit versions. The example may intentionally be incorrect or fail to compile if that helps explain the problem.

## Before opening a pull request

- Keep changes focused and describe the behavior they change.
- Follow the existing Swift style and document public APIs with DocC comments.
- Update README or documentation examples when public API usage changes.
- Run `swift test` and `swiftlint` when available; include the results in the pull request.
- For visible SwiftUI changes, include a screenshot or recording.

ToastKit currently supports iOS 17 and later, including iPadOS. Other platforms are not supported while testing is limited to iOS.
