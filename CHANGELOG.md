# Changelog

This changelog follows the version tags in Git. See [all tags](https://github.com/DavidRicardoWilde/swiftui-toastkit/tags) and [GitHub releases](https://github.com/DavidRicardoWilde/swiftui-toastkit/releases) for the canonical release history.

## [v0.2.1-beta.1](https://github.com/DavidRicardoWilde/swiftui-toastkit/tree/v0.2.1-beta.1)

- Added compact, regular, and large `ToastMetrics` presets.
- Added progress toasts, async progress reporting, cancellation, completion, and retry.
- Added batch dismissal, dismissal scopes, and fade, slide, and trail removal options.
- Added `ToastTheme.statusTint` for mapping an app palette to toast statuses.
- Added the Xcode demo app, including sizing, dismissal, and progress examples.

## [v0.2.0-beta.1](https://github.com/DavidRicardoWilde/swiftui-toastkit/tree/v0.2.0-beta.1)

- Added immediate swipe hints, vertical swipe actions, and mirrored top placement.
- Lifted the action track clear of the thumb during press-and-hold interaction.
- Added platform demo examples and multilingual documentation.

## [v0.1.0](https://github.com/DavidRicardoWilde/swiftui-toastkit/tree/v0.1.0)

- First tagged release of ToastKit: stacked, swipeable SwiftUI toasts with timing, configurable styles and themes, placement, and accessibility support.
